Foliora Studio Support

Support for the Foliora Studio Microsoft Word add-in.

Getting started

  • Open Foliora Studio from the Word ribbon and choose a tool.
  • Converter features are available without a paid plan.
  • Account-based features require you to sign in to a Foliora account.
  • AI OCR uses Foliora's server-side Gemini integration. Users do not need to provide a Gemini API key.

Common issues

  • Keep Microsoft Word updated and use a supported browser/webview.
  • If account or entitlement information looks outdated, sign out and sign in again, then use the Sync option in your profile.
  • If OCR fails, verify that you are signed in, the image is supported and under the documented size limit, and your OCR quota is available.

Report a problem

Open a GitHub issue with the feature name, steps to reproduce, and a screenshot when possible. Remove passwords, access tokens, private document content, and other sensitive information before submitting.
