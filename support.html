Foliora Studio Support

Support for the Foliora Studio Microsoft Word add-in.

Common issues

  • Keep Microsoft Word updated and use a secure HTTPS connection.
  • For AI OCR, verify that a valid Gemini API key and available API quota are configured.
  • For account or entitlement problems, sign out and sign in again.

Report a problem

Open a GitHub issue with the feature name, steps to reproduce, and a screenshot when possible.
