Foliora Studio — Privacy Policy

Effective date: September 21, 2026

Foliora Studio is a Microsoft Word add-in published by Foliora. This policy explains how information is handled when you use the add-in.

Document content

Formatting and conversion features operate on Word content selected for a requested feature.

AI OCR

If you use AI OCR/extraction, selected image or document content is sent to the AI service configured by the user. The current implementation uses Google Gemini when a Gemini API key is configured. Do not submit confidential material unless you are authorized to send it.

Account and usage data

Foliora Studio may use Supabase for account authentication, subscription/entitlement state, and usage/quota tracking. Those services have their own terms and privacy practices.

AI processing and API keys

AI OCR requests are sent through Foliora's secure server endpoint. The Google Gemini API key used by the service is stored server-side and is not exposed to, requested from, or stored in the Word add-in.

Data sharing

Foliora does not sell document content to advertisers. Data is transmitted to third-party services only when required for a feature the user explicitly invokes.

Contact

For support or privacy questions, use the Foliora Studio Support page.
